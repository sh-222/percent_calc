# НПД Калькулятор (percent_calc)

Мини-приложение для самозанятых: вводите сумму, которую хотите получить на руки, — получаете сумму к выставлению в счёте и налог для ставок **4 %** (физлица) и **6 %** (юрлица и ИП).

**[⬇️ Скачать APK](../../releases/latest)** — последний релиз.

---

## Зачем

Самозанятый платит налог с суммы, указанной в чеке, а не с суммы, которая приходит ему на карту. Поэтому «хочу 50 000 ₽» и «выставлю счёт на 50 000 ₽» — разные числа. Приложение считает правильное:

```
сумма к счёту = сумма на руки ÷ (1 − ставка)
налог         = сумма к счёту × ставка
```

| Ставка | Формула | Пример: 50 000 ₽ на руки |
|--------|---------|--------------------------|
| 4 % (физлица) | сумма ÷ 0.96 | счёт **52 083.33 ₽**, налог 2 083.33 ₽ |
| 6 % (юрлица, ИП) | сумма ÷ 0.94 | счёт **53 191.49 ₽**, налог 3 191.49 ₽ |

## Возможности

- Два расчёта одновременно — для 4 % и для 6 %.
- Пересчёт на лету при вводе суммы, поддержка `.` и `,` как разделителя.
- Тап по любой сумме — копирование в буфер обмена (удобно вставлять в счёт или чек).
- Показ формулы расчёта: видно, откуда взялась каждая цифра.
- Только портретная ориентация, Material 3, тёмная/светлая тема по системе.

## Установка APK

1. Откройте [страницу релизов](../../releases) и скачайте `percent-calc-vX.Y.Z.apk` из последнего тега.
2. На телефоне разрешите установку из неизвестных источников для файлового менеджера или браузера.
3. Установите и откройте «НПД Калькулятор».

APK из релизов собран в `--release` и подписан debug-ключом (для установки вручную этого достаточно, для публикации в Google Play — нет).

## Сборка из исходников

Нужен Flutter (stable, проверено на 3.38.7 / Dart 3.10) и Android SDK.

```bash
flutter pub get
flutter build apk --release
# готовый файл: build/app/outputs/flutter-apk/app-release.apk
```

Запуск на десктопе (Linux):

```bash
flutter run -d linux
```

Новая версия выпускается тегом — GitHub Actions соберёт APK и приложит его к релизу:

```bash
# версия в pubspec.yaml: version: 1.1.0+2 (после «+» — versionCode для Android)
git tag v1.1.0 && git push origin v1.1.0
```

## Структура

```
lib/
├── main.dart                # экран калькулятора: ввод и пересчёт
├── models/tax_result.dart   # модель результата: ставка, налог, сумма счёта
└── widgets/result_card.dart # карточка результата с копированием
assets/images/icon.png       # иконка приложения (flutter_launcher_icons)
```

Расчёт — единственная бизнес-логика, живёт в `TaxResult` и `CalculatorPageState._calculate()`.
